# workpro

업무 회의록 정리 도구 **워크프로**의 첫 판입니다. 회의 녹취나 메모를 붙여넣으면 결정 사항과 담당자별 할 일을 뽑아 정리합니다.

## 실행 방법

- 올려 둔 페이지: https://daonwave323-dot.github.io/workpro/ (GitHub Pages를 켠 뒤 열립니다)
- 내려받아 쓰기: `index.html`(또는 `워크프로-2026-11-25.html`)을 브라우저로 열면 바로 실행됩니다. 설치·서버·로그인이 필요 없습니다.

## 파일

- `index.html` — 워크프로 첫 판 (날짜 붙은 파일과 같은 내용, 주소로 바로 열기 위한 사본)
- `워크프로-2026-11-25.html` — 2026-11-25에 만든 첫 판 원본

## 기능

- 회의 목록 / 원본(발언자별·타임스탬프) / 정리(요약·결정 사항·담당자별 할 일) 3단 화면, 좁은 화면에서는 세로로 쌓임
- 붙여넣은 글에서 발언자와 타임스탬프를 나누고, 결정 사항·할 일·담당자를 규칙 기반으로 정리
- 할 일 완료 체크, 회의 정보 수정, 삭제, 정리 결과 복사, 인쇄/PDF 저장
- 백업 내보내기·불러오기, 다크/나이트 테마

## 데이터

회의 내용은 서버로 전송되지 않고 쓰는 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터를 지우면 함께 사라지므로, 남길 기록은 백업 내보내기로 파일을 받아 두세요.
