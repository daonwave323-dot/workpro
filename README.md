# workpro

업무 회의록 정리 도구 **워크프로**입니다. 회의 녹취나 메모를 붙여넣으면 결정 사항과 담당자별 할 일을 뽑아 정리하고, 할 일을 캘린더·공유 시트로 내보냅니다. 2026-11-26 판에서 라이트 테마, 할 일 내보내기, 미완료 할 일 모아 보기, 참석자 필터, 안건 템플릿, 녹음 전사, 요약 카드 이미지를 더했습니다.

## 실행 방법

- 올려 둔 페이지: https://daonwave323-dot.github.io/workpro/
- 내려받아 쓰기: `index.html`(또는 `워크프로-2026-11-25.html`)을 브라우저로 열면 바로 실행됩니다. 설치·서버·로그인이 필요 없습니다. 파일 이름은 첫 판 날짜 그대로 두었고 내용은 `index.html`과 같습니다.

## 파일

- `index.html` — 지금 쓰는 판 (주소로 바로 열기 위한 사본)
- `워크프로-2026-11-25.html` — `index.html`과 같은 내용의 사본 (날짜 파일명 유지)

## 기능

- 회의 목록 / 원본(발언자별·타임스탬프) / 정리(요약·결정 사항·담당자별 할 일) 3단 화면, 좁은 화면에서는 세로로 쌓임
- 붙여넣은 글에서 발언자와 타임스탬프를 나누고, 결정 사항·할 일·담당자를 규칙 기반으로 정리
- 할 일 완료 체크, 회의 정보 수정, 삭제, 정리 결과 복사, 인쇄/PDF 저장
- 백업 내보내기·불러오기
- 테마 3종: 라이트 → 다크 → 나이트 (오른쪽 위 버튼, 브라우저에 기억)
- 할 일 내보내기: `.ics` 캘린더 파일(기한을 날짜로 읽어 종일 일정으로), 공유 시트용 텍스트
- 미완료 할 일 모아 보기: 모든 회의의 미완료 할 일을 기한순으로. 체크하면 원래 회의 항목도 함께 완료
- 참석자 필터: 회의 목록을 참석자 이름으로 거르기
- 안건 템플릿: 상인회 미팅 / 임대관리 점검 / 일반 회의 틀
- 녹음 + 전사: 회의를 녹음해 AssemblyAI로 전사하고 결과를 원본 칸에 넣기 (아래 '녹음 전사 키' 참고)
- 요약 카드: 제목·날짜·참석자·결정 사항·할 일 수를 담은 1080×1350 PNG (이미지 저장 / 공유 시트)

## 녹음 전사 키 (AssemblyAI)

- 앱 오른쪽 위 **설정**(슬라이더 아이콘)에서 개인 API 키를 붙여넣으면 **그 브라우저(localStorage)에만** 저장됩니다.
- 키는 이 저장소와 코드에 들어 있지 않습니다. 녹음할 때만 브라우저에서 AssemblyAI로 직접 전달됩니다.
- 공용 기기에서는 키를 저장하지 마세요. 백업 JSON에도 키는 포함되지 않습니다.

## 데이터

회의 내용은 서버로 전송되지 않고 쓰는 브라우저의 localStorage(보조로 IndexedDB)에만 저장됩니다. 브라우저 데이터를 지우면 함께 사라지므로, 남길 기록은 백업 내보내기로 파일을 받아 두세요. 녹음 파일 자체는 저장되지 않고, 전사에만 쓰입니다(필요하면 '녹음 파일 저장'으로 내려받으세요).
